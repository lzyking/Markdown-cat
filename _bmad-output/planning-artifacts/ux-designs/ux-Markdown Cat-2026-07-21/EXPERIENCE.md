# EXPERIENCE.md — Markdown Cat

## Foundation

Markdown Cat 是一款 **macOS 桌面应用**，基于 Tauri 2.x + Web 前端构建。视觉身份参考 [DESIGN.md](DESIGN.md)。MVP 只提供深色主题，界面固定为**标题栏 + 菜单栏 + 等宽双栏编辑区 + 状态栏**。整个界面不支持自定义布局，双栏始终可见，且不可隐藏或收起。

本体验文档负责定义：信息架构、组件行为、状态模式、交互原语、无障碍底线、关键流程。所有视觉规格（颜色、字体、间距、圆角）引用 DESIGN.md 中的 token。

## Information Architecture

| Surface | 位置 | 目的 | 来源 |
|---|---|---|---|
| 主编辑窗口 | 应用启动后唯一主窗口 | 左栏编辑源码，右栏预览 | PRD FR-1、FR-3、FR-4 |
| 标题栏 | 窗口顶部 | 显示文件名、保存状态 | PRD FR-1、FR-5 |
| 菜单栏 | 标题栏下方 | 提供 macOS 标准菜单入口，MVP 仅「设置保存路径」有效 | PRD FR-7 |
| 状态栏 | 窗口底部 | 显示保存状态、行列号、文档类型 | PRD FR-5、FR-6 |
| 设置保存路径对话框 | 居中浮层 | 修改默认 `.md` 保存路径 | PRD FR-7 |
| 保存失败提示 | 状态栏 + 可选 toast | 明确提示保存失败原因 | PRD FR-6 |

MVP 没有侧边栏、文件树、标签页、多窗口、设置面板。所有交互集中在一个主窗口和唯一一个对话框中。

## Voice and Tone

微文案原则：

| 场景 | 文案示例 | 不使用的文案 |
|---|---|---|
| 保存成功 | 已保存至 New_20260721_143052.md | 保存成功 ✓ / 已保存 |
| 保存失败 | 保存失败：路径不可写 | 错误 / 无法保存 |
| 空状态 | 开始输入 Markdown，右侧将实时预览 | 欢迎使用 Markdown Cat！ |
| 设置路径 | 选择 Markdown 文件的默认保存目录 | 请选择你的笔记目录 |
| 菜单项 | 设置保存路径… | 保存路径设置 |

语气应为工具感、安静、不打扰。避免感叹号、emoji、营销式语言。失败提示必须说明具体原因，而不是仅显示「失败」。

## Component Patterns

| 组件 | 用途 | 行为规则 |
|---|---|---|
| 标题栏 | 窗口信息 | 显示当前文件名，文件名不可直接编辑；右侧显示保存状态。 |
| 菜单栏 | 顶层导航 | 菜单项：Markdown Cat、文件、编辑、视图、帮助。MVP 仅「Markdown Cat > 设置保存路径…」触发对话框；其余可保留标准占位或灰色不可用。 |
| 源码编辑器 | 输入 Markdown 源码 | 始终位于左栏，不可关闭。支持撤销/重做/复制/粘贴/全选。按键触发防抖保存。 |
| 预览区 | 渲染 Markdown | 始终位于右栏，只读。输入时 100ms 内更新，滚动位置不随输入跳动。 |
| 状态栏 | 状态反馈 | 左侧显示保存状态，右侧显示行列号与文档类型。 |
| 保存路径对话框 | 修改保存路径 | 打开系统文件夹选择器，仅允许选择已存在目录。确认后路径写入配置并立即生效。 |

## State Patterns

| 状态 | 出现位置 | 处理 |
|---|---|---|
| 初始启动 | 主窗口 | 源码编辑器空白，光标闪烁；预览区显示空状态提示。 |
| 正在输入 | 源码编辑器 | 按键触发状态更新，但保存 300ms 防抖后执行。状态栏显示上次保存状态，直到新保存完成。 |
| 保存成功 | 状态栏 | 显示「已保存至 {filename}」，文字颜色使用 `{colors.success}`。 |
| 保存失败 | 状态栏 + 保持可见 | 显示「保存失败：{reason}」，文字颜色使用 `{colors.error}`，保持可见直到下一次成功保存或用户关闭提示。 |
| 配置读取失败 | 状态栏 | 静默回退到默认路径规则，状态栏显示「已回退到默认保存路径」提示（不阻断）。 |
| 应用目录不可写 | 保存失败 | 提示「保存失败：应用目录不可写，请设置保存路径」，用户可点击菜单设置路径。 |
| 设置路径对话框打开 | 居中浮层 | 主窗口不可交互，按 Esc 或点击取消关闭。 |
| 无内容 | 预览区 | 显示空状态提示。 |

## Interaction Primitives

### 键盘

Markdown Cat 为轻量工具，不强调快捷键，但支持标准编辑操作：

- `⌘Z` / `⌘ShiftZ` — 撤销 / 重做
- `⌘C` / `⌘V` / `⌘X` / `⌘A` — 复制、粘贴、剪切、全选
- `⌘,` — 触发「设置保存路径」（可选，待实现时添加；MVP 不强求）
- `Esc` — 关闭设置保存路径对话框
- `Tab` / `Shift+Tab` — 在对话框按钮间切换焦点
- `Enter` — 在对话框中确认当前按钮
- `Space` — 在菜单中激活选中项

### 鼠标

- 点击菜单「Markdown Cat > 设置保存路径…」打开对话框。
- 点击对话框「选择…」按钮打开系统文件夹选择器。
- 点击对话框「确认」保存路径，点击「取消」关闭对话框。
- 源码编辑器与预览区均可滚动，但两者滚动不强制联动。

### 禁止行为

- 不允许隐藏源码编辑器或预览区。
- 不允许拖拽改变双栏比例（MVP 固定 1:1）。
- 不允许在预览区直接编辑内容。
- 不允许使用右键菜单进行自定义操作（保留系统默认右键菜单）。

## Accessibility Floor

- 所有文字对比度符合 WCAG 2.2 AA 标准（深色背景上的文字色已按此设计）。
- 菜单项和对话框按钮支持键盘操作。
- 保存失败状态除颜色变化外，文字内容明确说明失败原因，避免色盲用户仅依赖颜色。
- 源码编辑器支持标准 macOS 辅助功能（VoiceOver 可朗读编辑区）。
- 状态栏保存提示不应自动消失过快，至少保持可见直到下一次成功保存或用户关闭。

## Responsive & Platform

MVP 仅针对 macOS 桌面设计。窗口尺寸策略：

- 最小窗口尺寸：800 × 500px。
- 默认启动尺寸：1100 × 700px。
- 双栏始终等宽，随窗口宽度变化同步缩放。
- 窗口高度变化时，主编辑区垂直扩展，标题栏/菜单栏/状态栏高度不变。
- 不支持窗口全屏时的特殊布局（保持等宽双栏）。

## Inspiration & Anti-patterns

### 借鉴

- **Obsidian**：深色沉浸感、双栏可写可读模式、无干扰编辑界面。
- **Typora**：实时预览思路，但保留源码编辑的控制力。
- **macOS 原生应用**：标题栏/菜单栏/状态栏的层级关系，系统对话框行为。

### 拒绝

- **单栏实时预览优先**：Markdown Cat 保留源码控制力，不隐藏源码。
- **复杂工作空间/文件树**：MVP 没有文档管理，保持单一文档界面。
- **富工具栏**：MVP 没有格式工具栏，避免界面拥挤。
- **动画装饰**：不使用启动动画、保存成功动画等过渡效果，保持启动快速、反馈直接。

## Key Flows

### Flow 1 — 小林在受控 Mac 上打开并记录工作日志

1. 小林双击应用图标，应用在 3 秒内打开。
2. 主窗口呈现：标题栏显示 `New_20260721_143052.md`，状态栏显示「已保存至…」。
3. 左栏源码编辑器为空，光标闪烁；右栏显示空状态提示。
4. 小林输入 Markdown 工作日志。每输入一个字符，预览区在 100ms 内更新。
5. 他停止输入约 300ms，状态栏显示「已保存至 {filename}」。
6. 他关闭应用，无需额外保存操作。

**高潮**：小林没有点击任何保存按钮，内容已安全写入 `.md` 文件。

**边缘情况**：如果应用目录不可写，状态栏显示「保存失败：应用目录不可写，请设置保存路径」，编辑器内容保留。小林点击菜单「Markdown Cat > 设置保存路径…」，选择 `~/Notes`，确认后重新保存成功。

### Flow 2 — 小林修改默认保存路径

1. 小林已经写了一会儿，希望后续文档保存到 `~/Notes`。
2. 他点击菜单「Markdown Cat > 设置保存路径…」。
3. 设置保存路径对话框居中弹出，显示当前路径。
4. 他点击「选择…」，系统文件夹选择器打开，他选择 `~/Notes`。
5. 点击「确认」，对话框关闭，状态栏显示「保存路径已更新」。
6. 当前已打开的文档位置不变，后续新建文档保存到 `~/Notes`。

**高潮**：保存路径持久化，重启应用后仍然有效。
