## 手动安装 Rust 1.80+ 的步骤

请在终端（macOS）中逐行执行：

```bash
# 1. 下载 rustup 安装脚本
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs -o /tmp/rustup-init.sh

# 2. 执行安装，使用 -y 参数自动确认
sh /tmp/rustup-init.sh -y --default-toolchain stable

# 3. 让当前终端环境变量生效
source "$HOME/.cargo/env"

# 4. 验证版本
rustc --version
cargo --version
```
